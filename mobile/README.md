# Reloved for Android

The Android app is a thin native shell (Capacitor) around the live site at https://reloved-pwa.vercel.app.
The site and its API are deployed by Vercel exactly as before; **updating the website updates the app instantly,
without a new Play Store release.** A new Play Store upload is needed only when you change this folder
(icons, native plugins, the app version).

## What is in here
| Path | What it is |
| --- | --- |
| `capacitor.config.json` | App id `com.reloved.app`, name, and the website the app opens |
| `package.json`, `package-lock.json` | Capacitor and its plugins, pinned |
| `scripts/make-icons.mjs` | Draws the icon, splash and store graphics (already run; the PNGs are committed) |
| `scripts/patch-android.mjs` | Sets version numbers and release signing in the generated Android project |
| `resources/` | Icon and splash sources used to generate every Android size |
| `store/` | Store icon, feature graphic, screenshots and `listing.md` (all the text for Play Console) |
| `www/index.html` | Placeholder; the real content comes from the website |
| `android-release.yml` | The GitHub workflow that builds the app: a test APK, and the signed `.aab` for Play. It must live at `.github/workflows/android-release.yml` (see step 5 of the guide) |

The `android/` folder is generated by the workflow and is deliberately not committed.

## How you build it (no Android Studio needed)
See `PLAY-STORE-GUIDE.md` in this folder: one-time setup, then Actions -> Android app -> Run workflow.

## Known limits of this version
- The app needs an internet connection (it shows the live site). A short offline message is not built yet.
- Push notifications are not included yet (need a Firebase project). Chat shows a badge while the app is open.
- Online payments and seller payouts are not switched on yet; Google reviewers will test checkout, so finish
  Razorpay before the production release.
