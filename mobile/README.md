# Reloved for Android

The Android app is a Capacitor app that **ships the website's screens inside it** (copied from `../web` at build
time), so it opens instantly and shows an offline notice when there is no connection. Data still comes from the live
API at https://reloved-pwa.vercel.app/api/v1 (the same Vercel API the website uses).
**Every change to the website's screens now needs a new Play Store upload** (run the workflow again with a higher
version code); API changes still go live at once.

Inside the app the login works differently from the website: the API returns the refresh token in the response (the app
sends the header `X-Client: app`) and the app keeps it in private app storage. The Vercel **API project** must list
`https://localhost` in `CORS_ORIGINS` (the app's origin), otherwise every request from the app is rejected.

## What is in here
| Path | What it is |
| --- | --- |
| `capacitor.config.json` | App id `com.reloved.app`, name, and the app's settings (screens are bundled, no live site) |
| `package.json`, `package-lock.json` | Capacitor and its plugins, pinned |
| `scripts/make-icons.mjs` | Draws the icon, splash and store graphics (already run; the PNGs are committed) |
| `scripts/patch-android.mjs` | Sets version numbers and release signing in the generated Android project |
| `resources/` | Icon and splash sources used to generate every Android size |
| `store/` | Store icon, feature graphic, screenshots and `listing.md` (all the text for Play Console) |
| `scripts/build-www.mjs` | Copies `../web` into `www/` before every build (the workflow does this) |
| `www/` | Generated copy of the website screens that go inside the app (rebuilt each time) |
| `android-release.yml` | The GitHub workflow that builds the app: a test APK, and the signed `.aab` for Play. It must live at `.github/workflows/android-release.yml` (see step 5 of the guide) |

The `android/` folder is generated by the workflow and is deliberately not committed.

## How you build it (no Android Studio needed)
See `PLAY-STORE-GUIDE.md` in this folder: one-time setup, then Actions -> Android app -> Run workflow.

## Known limits of this version
- Without a connection the app opens and shows an offline notice, but listings and orders need the internet (no offline browsing of data).
- Push notifications are not included yet (need a Firebase project). Chat shows a badge while the app is open.
- Online payments and seller payouts are not switched on yet; Google reviewers will test checkout, so finish
  Razorpay before the production release.
